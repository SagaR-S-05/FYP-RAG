# File Manifest

Complete list of all files in the project and their purposes.

- Lists all project dependencies (React, Tailwind, Radix UI, etc.)
- Defines npm scripts (dev, build, preview, lint)
- Project metadata and version

- Auto-generated file that locks dependency versions
- Ensures consistent installations across different machines
- **Do not edit manually**

- Vite build tool configuration
- React plugin setup
- Development server settings

### `eslint.config.js`
- ESLint linting rules
- Code quality standards
- React-specific rules

### `index.html`
- Main HTML template
- Entry point for the application
- Loads `/src/main.jsx`

- Specifies files Git should ignore
- Excludes node_modules, dist, and build artifacts

## Source Files (`/src`)

### `main.jsx`
- Application entry point
- Renders the root App component
- Sets up React StrictMode
- **Purpose:** Bootstrap the React application

### `App.jsx`
- Main application component
- Manages global state (chats, folders, videos, profile)
- Handles localStorage persistence
- Navigation logic
- **Purpose:** Central hub that orchestrates all features

### `index.css`
- Global CSS styles
- Tailwind CSS v4 configuration
- CSS custom properties (colors, spacing)
- Typography base styles
- **Purpose:** Application-wide styling

### `App.css`
- Additional app-specific styles
- Currently minimal (for future custom styles)
- **Purpose:** Component-specific overrides

## Component Files (`/src/components`)

### `ChatInterface.jsx`
- Chat-style UI for video generation
- Message history display
- Video generation mock logic
- Chat management (create, delete)
- **State:** inputValue, isGenerating, deleteChatId
- **Props:** chats, currentChatId, setCurrentChatId, saveChats

### `VideoGallery.jsx`
- Video library with folder organization
- Folder management (create, rename, delete)
- Video operations (move, delete, download)
- FIFO logic for Recents folder
- **State:** selectedFolder, editingFolderId, moveVideoDialogOpen, etc.
- **Props:** videos, chats, folders, saveFolders, videoFolders, saveVideoFolders

### `ProfilePage.jsx`
- User profile settings
- Name and email editing
- Account statistics display
- Avatar with initials
- **State:** name, email, isSaved
- **Props:** userProfile, saveUserProfile

### `AboutPage.jsx`
- Information about Interactive Manim Video Generator
- How Manim integration works
- Step-by-step explanation
- FAQ section
- **State:** None (static content)
- **Props:** None

### `lib/utils.js`
- Utility functions
- `cn()` function for className merging
- Combines clsx and tailwind-merge
- **Purpose:** Clean className composition

## Data Model (localStorage)

The application stores data in browser localStorage:

### `chats` (LocalStorage)
```javascript
{
  id: string,
  title: string,
  messages: Array<{
    id: string,
    role: 'user' | 'assistant',
    content: string,
    videoUrl?: string,
    timestamp: Date
  }>,
  createdAt: Date,
  updatedAt: Date
}
```

### `folders` (LocalStorage)
```javascript
{
  id: string,        // 'recents' or 'folder-{timestamp}'
  name: string,
  createdAt: Date
}
```

### `videoFolders` (LocalStorage)
```javascript
{
  [videoId]: folderId  // Maps video IDs to folder IDs
}
```

### `userProfile` (LocalStorage)
```javascript
{
  name: string,
  email: string,
  avatar?: string
}
```

## Modification Guide

### To add a new page:
1. Create component in `/src/components/NewPage.jsx`
2. Import in `/src/App.jsx`
3. Add navigation button in App.jsx sidebar
4. Add state for new page in `currentPage` state

### To add new styling:
1. Global styles → `/src/index.css`
2. Component styles → inline Tailwind classes
3. Custom CSS → `/src/App.css`

### To modify colors:
1. Edit CSS custom properties in `/src/index.css`
2. Update `:root` variables
3. Colors use Sage Garden palette

### To add dependencies:
```bash
npm install package-name
```
Then import in your component

## Key Conventions

- **File naming:** PascalCase for components (e.g., `ChatInterface.jsx`)
- **Function naming:** camelCase (e.g., `handleSubmit`)
- **Component exports:** Named exports for components
- **Default exports:** Only `App.jsx` uses default export
- **Styling:** Tailwind utility classes, inline in JSX
- **State management:** React useState + localStorage
- **Type safety:** None (pure JavaScript/JSX, not TypeScript)
